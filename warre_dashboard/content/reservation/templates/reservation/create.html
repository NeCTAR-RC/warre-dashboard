To make a reservation, select an available time slot from the table below. You can customise the reservation start and end dates within the available time slot. Reservations are specified in days and must be a minimum of 1 day. All flavors have a maximum number of days they can be reserved for, which is shown in the flavor details.

G1 - Visualisation GPU

G1 instances come with Nvidia A40s which brings state-of-the-art features for ray-traced rendering, simulation and virtual production.

G2 - Compute GPU

G2 instances come with the latest generation Nvidia A100 GPUs and provide the highest performance for machine learning training and high performance computing in the cloud.

H4 - Large RAM

H4 instance come with RAM starting from h4.xsmall with 180G to the h4.xxlarge with 1920G.
